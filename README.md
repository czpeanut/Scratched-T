# 焦土台灣 (Hollow Runner) - 2D 俯視角末日動作射擊

《焦土台灣：第一章 甦醒》現已重構為 **2D 俯視角（Top-Down Perspective）戰術末日生存射擊動作遊戲**。

遊戲保留了末日廢墟的嚴肅氛圍、完整的故事情節、近戰與槍械系統，並引入了專為俯視角設計的**「遠射瞄準縮小準星（Dynamic Reticle Aim-Down-Sights）」**機制。

技術棧現已全面遷移至 **React 19 + TypeScript + Vite**，相容桌面端與行動端觸控操作。

---

## 核心特色

1. **2D 俯視角流暢戰鬥**
   - 8 方向平滑移動與轉向（WASD / 類比搖桿）。
   - 戰術翻滾閃避（Dodge Roll，具備無敵幀與塵土特效）。
   - 體力值（Stamina）管理系統，奔跑與翻滾皆需體力調配。

2. **近戰打擊感與連擊判定 (Melee)**
   - **赤手拳頭 (Fists)**：快速短距推擠打擊。
   - **廢墟棍棒 (Stick)**：揮擊前搖較長，但具備極大擊退力與打擊硬直（Hitstop）。
   - **戰術軍刀 (Knife)**：極速突刺，刀光殘影與高穿透殺傷。

3. **【核心機制】遠射瞄準縮小準星 (Aim-Down-Sights Reticle)**
   - **腰射 (Hip-fire)**：準星擴散半徑較大，移動或連續射擊會產生 Bloom 後座力散布。
   - **長按瞄準 (ADS)**：按住滑鼠右鍵（RMB）、鍵盤 `U` 鍵或觸控「瞄準」按鈕，準星四角標記與光環動態向中心收斂（從約 36px 縮窄至 4-5px 針尖精度）。
   - **瞄準鎖定 (AIM LOCK)**：當瞄準度達到 98% 以上時，發出蜂鳴鎖定音效，射程增加 25%，命中暴擊且具備精準雷射導引線！

4. **第一章劇情：甦醒**
   - 甦醒於廢墟醫院病房，閱讀五年前泛黃的戒嚴物資公告。
   - 在走廊取得防身棍棒，擊退第一名廢土劫匪。
   - 抵達老周的廢墟避難所，了解戰後五年的台灣局勢，接過老周託付的 9mm 軍用手槍。
   - 穿越廢棄省道十字路口，取得軍用腎上腺素解鎖奔跑與翻滾。
   - 突破軍用自動哨戒防禦砲塔，沿舊鐵軌前往南站。

5. **AI 美術**
   - 角色、道具、地面與牆面材質都由 Gemini 生成，經 `tools/td_art.py` 後製成像素風格素材（`public/assets/td/`）。
   - 3/4 俯視牆體與深度排序、視線遮擋光照、暖色黃昏色調。
   - 觸控按鈕只在手機 / 平板等觸控裝置顯示。

6. **詳細開發與接手文件**
   - 請參閱專案根目錄下的 [`HANDOVER.md`](./HANDOVER.md)，包含完整架構、物理公式、擴展指南。

## 操作指南

| 動作 | 鍵盤 / 滑鼠 | 觸控按鈕 |
| :--- | :--- | :--- |
| **移動** | `W` `A` `S` `D` / 方向鍵 | 左下虛擬方向鍵 (D-Pad) |
| **攻擊 / 開火** | 滑鼠左鍵 (LMB) / `J` | 右側【攻擊】按鈕 |
| **瞄準縮圈 (ADS)** | 滑鼠右鍵 (RMB) / `U` (長按) | 右側【瞄準】按鈕 (長按) |
| **戰術翻滾** | 空白鍵 (`Space`) | 右側【翻滾】按鈕 |
| **奔跑** | `Shift` / `L` | 右側【奔跑】按鈕 |
| **切換武器** | 數字鍵 `1` `2` `3` `4` / `Q` | 右側【換槍】按鈕 / 頂部 HUD |
| **交談 / 調查** | `E` | 右側【交談】按鈕 |
| **暫停** | `ESC` / `P` | 暫停按鈕 |
| **靜音切換** | `M` | 頂部音效按鈕 |
| **重新開始** | `R` | 死亡畫面按鈕 |

## 本機開發與建置

```bash
# 安裝依賴
npm install

# 啟動開發伺服器 (Port 3000)
npm run dev

# 專案建置
npm run build

# 程式碼檢查
npm run lint

# 重建俯視角美術（需要 Pillow，不需 API 金鑰）
python3 tools/td_art.py
```
